## 📖 About the Project

The **Airline Management System** is a web application developed using the Django framework. It demonstrates the development of an airline-related website with a user interface for viewing schedules and accessing flight reservation pages.

The project uses Python for backend development, Django for web application functionality, HTML and CSS for the user interface, and SQLite for database management.

This project demonstrates practical web development concepts, including backend programming, database integration, and web interface design.

## ✨ Features

- ✈️ Airline-themed web interface
- 🏠 Homepage with airline-related information
- 📅 Flight schedule interface
- 🔍 Flight reservation interface
- 🐍 Python and Django backend
- 🗄️ SQLite database integration
- 🎨 HTML templates and static assets
- 🌐 Browser-based application access

## 🚀 Getting Started

Follow these instructions to run the project locally.

### Prerequisites

Make sure you have installed:

- Python 3
- pip
- Git
- A modern web browser

## ⚙️ Installation

### 1. Clone the Repository

```bash
git clone https://github.com/Harashishsingh/Airline.git
```

### 2. Navigate to the Project Directory

```bash
cd Airline
```

### 3. Create a Virtual Environment

**Windows:**

```bash
py -m venv venv
```

Activate the environment:

```bash
venv\Scripts\activate
```

**macOS / Linux:**

```bash
python3 -m venv venv
source venv/bin/activate
```

### 4. Install Dependencies

If the repository contains a `requirements.txt` file, run:

```bash
python -m pip install -r requirements.txt
```

If no dependency file is available, install Django and any other packages required by the project:

```bash
python -m pip install django
```

### 5. Apply Database Migrations

```bash
python manage.py migrate
```

### 6. Start the Development Server

```bash
python manage.py runserver
```

## 🌍 Running the Application

Once the development server starts, open the following address in your browser:

```text
http://127.0.0.1:8000/
```

The application should be accessible locally if its dependencies and configuration are set up correctly.

## 🗄️ Database

The project uses **SQLite** for data storage.

SQLite provides a lightweight database solution suitable for development and small applications. Django migrations can be used to create and update database tables according to the project's models.

Before sharing the repository publicly, review the database for sensitive information or personal records.
